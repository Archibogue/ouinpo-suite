# Ce que fait le plugin

OuInPo Suite aide un enseignant a organiser des contenus et suivis NSI/SNT dans WordPress.

Il peut :

- importer des packs pedagogiques JSON ;
- afficher des exercices, indices, solutions et sujets pratiques selon les reglages ;
- suivre la progression des eleves connectes ;
- gerer classes, competences, badges, flashcards et devoirs ;
- proposer des fonctions IA optionnelles si elles sont configurees.

Il ne fait pas automatiquement :

- validation institutionnelle des contenus ;
- anonymisation de donnees deja saisies ;
- publication controlee par defaut de toutes les solutions ;
- verification parfaite des reponses IA ;
- sauvegarde complete du site WordPress.

Pour une beta, tester sur une installation pilote avant un usage large.
