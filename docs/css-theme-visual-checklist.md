# Checklist visuelle CSS themes

Objectif : verifier manuellement que les themes `neutral`, `ouinpo` et `bsio` chargent les bons fichiers apres le decoupage CSS, sans chercher a modifier le rendu.

## Procedure navigateur

1. Ouvrir la page a verifier dans un navigateur connecte avec le role adapte.
2. Dans l'administration OuInPo Suite, passer le style public successivement en `neutral`, `ouinpo`, puis `bsio`.
3. Recharger la page publique apres chaque changement ; vider le cache navigateur si un ancien fichier CSS reste visible.
4. Ouvrir `F12 > Network > CSS`.
5. Verifier les fichiers charges :
   - en `neutral` : `assets/css/themes/neutral.css` et le CSS front du module concerne ;
   - en `ouinpo` : les couches `assets/css/themes/ouinpo/*.css`, le module `assets/css/themes/ouinpo/modules/*.css`, et le CSS front du module concerne ;
   - en `bsio` : les couches `assets/css/themes/bsio/*.css`, le module `assets/css/themes/bsio/modules/*.css`, et le CSS front du module concerne.
6. Verifier l'absence de l'ancien gros fichier `assets/css/themes/ouinpo.css` ou `assets/css/themes/bsio.css` comme source principale. Ces fichiers peuvent exister pour compatibilite, mais ils ne doivent pas remplacer les fichiers decoupes.
7. Comparer rapidement les titres, panneaux, cartes, boutons, tableaux, badges, alertes, zones IA, fichiers joints, formulaires et etats responsive.
8. Noter toute difference volontairement non expliquee dans la colonne observations.

## Fichiers communs attendus

- Mode `neutral` : `assets/css/core/base.css`, `assets/css/themes/neutral.css`, puis le CSS front du module concerne.
- Mode `ouinpo` : `assets/css/core/base.css`, `assets/css/themes/ouinpo/foundation.css`, `assets/css/themes/ouinpo/content.css`, `assets/css/themes/ouinpo/components.css`, `assets/css/themes/ouinpo/legacy-overrides.css`, puis le CSS front et le module de theme concerne.
- Mode `bsio` : `assets/css/core/base.css`, `assets/css/themes/bsio/foundation.css`, `assets/css/themes/bsio/content.css`, `assets/css/themes/bsio/components.css`, `assets/css/themes/bsio/legacy-overrides.css`, puis le CSS front et le module de theme concerne.

## Notes de recette

- Les handles thematiques de modules peuvent etre enregistres avec une source vide en mode `neutral`; le fichier visible principal reste alors `themes/neutral.css`.
- Les fichiers `assets/css/themes/ouinpo.css` et `assets/css/themes/bsio.css` sont des fichiers de compatibilite courts. Ils ne doivent pas etre le fichier principal observe dans Network pour les modes decoupes.
- Pour les pages ecrites, verifier explicitement que `assets/css/front/written.css` est charge et qu'aucune dependance directe a `assets/css/front/practical.css` n'est necessaire.
- Pour chaque anomalie, noter le mode, la page, le fichier CSS observe dans Network et une capture si possible.
