# OuInPo - Dépôts & Ressources (v1.2.1)

Les ressources `.md` sont acceptées par le chargement privé existant. Les élèves
autorisés disposent du lien de téléchargement et de **Lire le Markdown** dans
la liste des fichiers. La lecture formatée ouvre un nouvel onglet et utilise
les mêmes contrôles de connexion, nonce et affectation que le téléchargement.
L'aperçu accepte jusqu'à 1 Mo ; les fichiers plus grands restent téléchargeables.
Le HTML actif et les images externes ne sont pas exécutés ou chargés dans l'aperçu.
Correctif critique : point-virgule manquant dans la sauvegarde du fichier (metabox) + metabox robuste (sélecteur Médiathèque).
